# 🌐 Vikram Mama Plot - 360° Stitched Panorama Studio

Interactive, fully-responsive 360° panorama and virtual tour studio for the Vikram Mama residential plot.

## 🌟 Features
- **16 On-Site Photos Stitched into a 360° Panorama**: Combines original site photos into a seamless 360-degree cylindrical panorama.
- **Three.js WebGL Engine**: Ultra-smooth real-time 360° panning, tilting, and field-of-view zooming.
- **Fully Responsive**: Optimized for desktop, tablets, and smartphones (iOS/Android) with dynamic viewport height (`100dvh`).
- **Touch-Friendly Controls**: Native mobile pinch-to-zoom and one-finger swipe.
- **Mobile Gyroscope / Motion Sensor Support**: Tilt and turn your phone in real space to look around the plot in 360°.
- **Collapsible Drawer**: Collapse or expand the thumbnail strip with one click for an unobstructed full-screen experience.
- **Live Compass HUD & Radar**: Dynamic heading indicator ($0^{\circ}$ to $360^{\circ}$ N, E, S, W) and directional radar needle.
- **Continuous Stitched Panorama Strip**: Inspect the ultra-wide stitched panorama and download the full-resolution image.

## 🚀 Getting Started
Simply clone or download this repository and open `index.html` in any modern web browser (Google Chrome, Microsoft Edge, Safari, Mozilla Firefox).

```bash
git clone https://github.com/aspiremediatechsolution-prog/vikram-mama.git
cd vikram-mama
# Open index.html in your browser
```

## 📁 Repository Structure
- `index.html`: Main responsive 360° virtual tour application.
- `images/`: Original site photos and video assets.
- `renders/`: High-resolution architectural and panoramic renders.
